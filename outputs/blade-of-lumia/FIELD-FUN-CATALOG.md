## 確定した設計指針（2026-07-05 ユーザー同席）

### 隠しの「気づかせ方」＝基本ヒント付き・ノーヒントは低率のご褒美 ✅確定
- **基本はヒント付き。** ヒントの語彙（配線済み）＝ひび割れ/焦げ跡のスキンタイル・近くの`sign`看板・`linesAfterBoss`のNPC噂・地形の不自然さ（草原に1本だけ浮いた岩など）。
- **ノーヒント秘密は低率（隠し総数の1〜2割目安）＝「気づいた人へのご褒美」。**
- **報酬の切り分け（重要）：** ノーヒント秘密の報酬は**進行に困らないもの限定**（ルピー・消耗品）。**進行に効く隠し（ハートのかけら・上位装備）は必ずヒント付き。**

### b3 の設計原則＝「フィールドはダンジョンの予告編」（2026-07-05 ユーザー確定）

再訪ポイントは**中くらい（数ヶ所）**だが、意味なく置かず**後で入るダンジョンの看板ギミックと同じ構造をフィールドで先に一度チラ見せする**（任天堂式の「本番前に低リスクで学ばせる」手法）。

| ダンジョン（看板ギミック） | フィールドでのチラ見せ（予告編） |
|---|---|
| D3 弓ゲート（`Y`遠隔スイッチを矢で撃つ） | 湖ぎわの草原に、矢で撃つと橋が架かる小さな`Y`スイッチ（先にルピー） |
| D4/D6 かがり火（ロウソクで`H`全点灯→道が開く） | 火山手前に、ロウソクで灯すと宝箱が出る1本のかがり火 |
| D6/D7 爆弾壁（`!`を爆破して進む） | 森の入口手前の岩壁を爆破すると近道／隠し洞窟 |
| D5/D8 はしご水渡り（`~`を1セル橋で渡る） | **湖地域で実装済み（9-4）＝既に予告編が存在** |
| D8/D7 笛reveal（笛で隠し入口が出る） | 沼の祭壇跡で笛を吹くと階段が生える小ネタ |
| 石押し（`*`STONE をスイッチに乗せる） | 草原の巨石を押すと下に隠し階段 |

**設計上の効能：** ①「この地形、前に見た」→ダンジョンで詰まりにくい（学習）／②再訪ポイントに必然性が生まれる（飾りでなく「あの構造だ」）／③**予告編は必ず対応ダンジョンより手前の地域に置く**（攻略順 D2→D3→D4→D6→D5→D8→D7 に沿わせる＝順序が効く）。報酬は進行必須でなく隠し・ルピー・かけら。
